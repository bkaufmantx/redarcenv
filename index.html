🧭 Pricing & Routing Model

Facility-suffixed item codes

Format PREFIX##-FAC (e.g. EFW01-AVA). The suffix exists because Zak bundles transport into the disposal price (no itemized freight or fuel surcharge), so all-in cost is intrinsically facility-specific.

Routing is layered

(1) all-in cost = disposal + EIS fees + transport/route density → (2) facility acceptance criteria (e.g. US Ecology Tulsa's 500ppm VOC limit) → (3) backup facility per stream (Tradebe backs up Avalon) → (4) approvals-dept conservatism (tribal knowledge).

Rate-selection priority

profile-specific > account-specific > tier-sheet default (B-tier, 55-gal) > item-code default. A/B/C tiers = 30/38/45% margin, with per-container-size breakouts.

CRM is genuinely empty — confirmed

Verified via admin token against the single correct org: 0 records across all core modules. The real data lives in Platform, not CRM. The "cluttered HubSpot pipeline" Zak sees is in Platform.

✅ Pre-Call Recon Complete — Estimate Structure Documented
Pulled real Estimate #229 (Lab Pack, Shield Medical Waste, $16,739) from Platform on June 10. Full field inventory documented — header, line items, boilerplate, vendor structure, margin math. We're not seeing the quote object cold in the Zak walkthrough.
Key findings:
  • Two-level object: Header (account/generator/totals) + line items (one per waste stream). 26 lines on a complex lab pack.
  • Three vendor types per estimate: RedArc (labor + transport) · TSDF like CRS (incineration, fuel blend, treatment) · Questar (supplies)
  • Item code is the atomic unit. Format: PREFIX##-VENDOR — encodes disposal route + chemical class + vendor. Same code can appear multiple times with different Notes (compatibility groups).
  • Notes field distinguishes waste streams within the same code — "Flammable/Toxic" vs. "Flammable/Corrosive" on INC14-AVA. Separate containers, same route.
  • Labor drives GP: 60 hrs of chemist labor = $3,360 GP ≈ 50% of total margin. 40.3% overall GM on this estimate.
  • Boilerplate is static — same T&C paragraph on every quote, stored in Pre_Line_Item_Content field.
  • ~760 item codes in Platform — quote tool needs search/filter, not a full list.

Margin math is clear

Customer price = vendor cost ÷ (1 − margin). e.g., NON01 55G at $45.10 vendor cost → A tier customer price = $45.10 ÷ 0.70 = $64.43.

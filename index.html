Platform Audit Findings 4 info ▶

Profile = core quoting object

A Profile ties one waste stream to one generator site and one disposal destination. Each Profile has vendor pricing per item code per container size (30G / 55G / 275G / 330G).

760 item codes in 20+ categories

Categories include ADM (admin/fees), ALT (alternate fuels), NON (non-hazardous), and many more. Each code has type (Disposal vs. Fees & Surcharges), unit, and pricing. Export is easy — just needs Zak's context walkthrough first.

Vendor vs. customer pricing split

Platform stores both what RedArc pays the disposal vendor AND what RedArc charges the customer — per item code per container size. Margin tiers (A/B/C) are applied at the customer pricing layer.

Pricing driver confirmed

Default_Account_Pricing_Level on Accounts = A/B/C = 30/38/45% gross margin on disposal + transport + fees.

Margin math is clear

Customer price = vendor cost ÷ (1 − margin). e.g., NON01 55G at $45.10 vendor cost → A tier customer price = $45.10 ÷ 0.70 = $64.43.

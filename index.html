Pricing & Routing Model + Data Drop (June 11) the foundation ▶

Facility-suffixed item codes

Format PREFIX##-FAC (e.g. EFW01-AVA). The suffix exists because Zak bundles transport into the disposal price (no itemized freight or fuel surcharge), so all-in cost is intrinsically facility-specific.

Routing is layered

(1) all-in cost = disposal + EIS fees + transport/route density → (2) facility acceptance criteria (e.g. US Ecology Tulsa's 500ppm VOC limit) → (3) backup facility per stream (Tradebe backs up Avalon) → (4) approvals-dept conservatism (tribal knowledge).

Rate-selection priority

profile-specific > account-specific > tier-sheet default (B-tier, 55-gal) > item-code default. A/B/C tiers = 30/38/45% margin, with per-container-size breakouts.

CRM is genuinely empty — confirmed

0 records across all core modules. The real data lives in Platform, not CRM. The "cluttered HubSpot pipeline" Zak sees is in Platform.

Platform Audit Findings 4 info ▶

Profile = core quoting object

A Profile ties one waste stream to one generator site and one disposal destination. Each Profile has vendor pricing per item code per container size (30G / 55G / 275G / 330G).

760 item codes in 20+ categories

Categories include ADM (admin/fees), ALT (alternate fuels), NON (non-hazardous), and many more. Each code has type (Disposal vs. Fees & Surcharges), unit, and pricing.

Vendor vs. customer pricing split

Platform stores both what RedArc pays the disposal vendor AND what RedArc charges the customer — per item code per container size. Margin tiers (A/B/C) are applied at the customer pricing layer.

Platform Estimate Structure — Recon quote-tool target ▶

Pulled real Estimate #229 (Lab Pack, $16,739) from Platform — the structure the quote tool's output must match:

  • Two-level object: header (account/generator/totals) + line items (one per waste stream). 26 lines on a complex lab pack.
  • Three vendor types: RedArc (labor + transport) · TSDF (incineration, fuel blend, treatment) · Questar (supplies).
  • Item code is the atomic unit (PREFIX##-VENDOR); same code repeats with different Notes for compatibility groups.
  • Labor drives GP: 60 hrs chemist labor ≈ 50% of margin; 40.3% overall GM on that estimate.

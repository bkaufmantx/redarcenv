Video Screenshot Tool

Turn a screen-demo recording into a timestamped transcript, then have Claude pull the exact screenshots it needs, on demand — so content from walkthroughs and screen-shares is instantly searchable, no scrubbing.

📄 Read the Guide (PDF) ⌥ View the code
Local utility · runs on Brian's Mac · no API keys, no per-video cost

How it works

1
Up front · automatic

Transcribe

Drop a recording on the app. Whisper turns the audio into a transcript with exact timestamps — the searchable map of everything said and when.

2
On demand · Claude

Grab the frame

You ask for a moment in plain English. Claude finds the line in the transcript and seeks that precise second — saving just that screenshot.

3
Instantly usable

Use the content

Claude reads the screenshot and works with it — for docs, quotes, walkthroughs, or grounding the quote tool against what was actually on screen.

You: "In the platform walkthrough, grab the screen where Zak opens the rate sheet."
Claude: finds "…now I'll open the rate sheet…" at 4:22 → grabs frame 00-04-22.jpg → reads it
Claude: "Here's the rate sheet view at 4:22 — it shows the A/B/C tier columns…"

Why it's built this way

On-demand, not a blanket dump

No wall of every-few-seconds screenshots. Frames are captured at the exact moment they're needed — more precise and nothing to wade through.

The transcript does the alignment

No need for a pre-timed transcript. The video's own audio is transcribed with real timestamps, so every spoken line already knows its time.

Fully local & free

ffmpeg + Whisper run on the Mac. No API keys, no per-video cost, works offline. A step toward owning the workflow end-to-end.

Covers silent moments too

If something important happens with no narration, an opt-in mode pre-extracts frames on every visual change so there's always something to look at.

Note — this is a local utility, not a web app. The tool runs on Brian's Mac because it works directly with the video files and Claude's filesystem (that's how Claude gets at the screenshots). This page is its home base: the guide and the backed-up code live here. To run it, drag a recording onto RedArc Video Tool.app — full steps are in the PDF guide above.
